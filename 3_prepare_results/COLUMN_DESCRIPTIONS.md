# Column Descriptions for Gene-Level Aggregated Results

Here we describe all columns in the gene-level aggregated output parquet files generated by the `aggregator.py` module.

---

## Gene Identifiers & Basic Metadata

### **gene_id**
- **Type:** String
- **Description:** Ensembl gene identifier (without version suffix, e.g., ENSG00000106144)
- **Source:** Input variant data, normalized to remove version numbers

### **gene_symbol**
- **Type:** String
- **Description:** HGNC gene symbol
- **Source:** GTF annotation

### **gene_type**
- **Type:** String
- **Description:** Gene biotype classification (e.g., protein_coding, lincRNA)
- **Source:** GTF annotation

### **chrom**
- **Type:** String
- **Description:** Chromosome identifier (e.g., chr7)
- **Source:** GTF annotation

### **TSS**
- **Type:** Integer
- **Description:** Transcription start site position (bp) on the chromosome
- **Source:** GTF annotation, strand-aware

### **is_mane**
- **Type:** Boolean
- **Description:** Whether this gene has a MANE Select transcript
- **Source:** MANE annotation

### **mane_transcript_id**
- **Type:** String
- **Description:** MANE Select transcript identifier (with version)
- **Source:** MANE annotation

---

## Gene Structural Features

### **genomic_length**
- **Type:** Integer
- **Description:** Total genomic span of the gene (bp), from start to end coordinates
- **Source:** GTF annotation

### **exonic_length**
- **Type:** Integer
- **Description:** Total length of all exonic regions (bp)
- **Source:** GTF annotation

### **intronic_length**
- **Type:** Integer
- **Description:** Total length of all intronic regions (bp)
- **Source:** GTF annotation

### **coding_length**
- **Type:** Integer
- **Description:** Total length of coding sequence (CDS) regions (bp)
- **Source:** GTF annotation

### **utr5_length**
- **Type:** Integer
- **Description:** Total length of 5' UTR regions (bp)
- **Source:** GTF annotation

### **utr_length**
- **Type:** Integer
- **Description:** Total length of all UTR regions (bp)
- **Source:** GTF annotation

---

## Variant Count Metrics

### **n_variants**
- **Type:** Integer
- **Description:** Total number of unique variants in this gene
- **Calculation:** Count of unique variant_id after deduplication by highest absolute effect

### **n_variants_common**
- **Type:** Integer
- **Description:** Number of common variants (AF ≥ 0.05)
- **Calculation:** Count where AF ≥ 0.05

### **n_variants_rare**
- **Type:** Integer
- **Description:** Number of rare variants (AF < 0.05)
- **Calculation:** Count where AF < 0.05

### **n_variants_common_perm**
- **Type:** Integer
- **Description:** Number of variants with permuted AF ≥ 0.05
- **Calculation:** Count where perm_AF ≥ 0.05
- **Note:** Only present when permuted AFs are available

### **n_variants_rare_perm**
- **Type:** Integer
- **Description:** Number of variants with permuted AF < 0.05
- **Calculation:** Count where perm_AF < 0.05
- **Note:** Only present when permuted AFs are available

### **variants_per_kb**
- **Type:** Float
- **Description:** Variant density normalized by genomic length
- **Calculation:** n_variants / (genomic_length / 1000)

---

## Spatial Window Variant Counts

### **n_variants_distal_upstream**
- **Type:** Integer
- **Description:** Variants in distal upstream region (-10kb to -2kb from TSS)

### **n_variants_proximal_upstream**
- **Type:** Integer
- **Description:** Variants in proximal upstream region (-2kb to -200bp from TSS)

### **n_variants_promoter_core**
- **Type:** Integer
- **Description:** Variants in core promoter region (-200bp to +200bp from TSS)

### **n_variants_down_proximal**
- **Type:** Integer
- **Description:** Variants in downstream proximal region (+200bp to +2kb from TSS)

### **n_variants_down_distal**
- **Type:** Integer
- **Description:** Variants in downstream distal region (+2kb to +10kb from TSS)

---

## Genetic Variance (Vg) Metrics

### **vg_predicted**
- **Type:** Float
- **Description:** Total predicted genetic variance for this gene
- **Formula:** Σ[2 × AF × (1 - AF) × β²] across all variants
- **Note:** Primary Vg metric using observed allele frequencies

### **vg_predicted_perm**
- **Type:** Float
- **Description:** Total predicted genetic variance using permuted allele frequencies
- **Formula:** Σ[2 × perm_AF × (1 - perm_AF) × β²]
- **Note:** Used as null expectation for selection analyses

### **vg_common**
- **Type:** Float
- **Description:** Genetic variance contribution from common variants (AF ≥ 0.05)
- **Calculation:** Sum of vg_contribution where AF ≥ 0.05

### **vg_rare**
- **Type:** Float
- **Description:** Genetic variance contribution from rare variants (AF < 0.05)
- **Calculation:** Sum of vg_contribution where AF < 0.05

### **vg_common_perm**
- **Type:** Float
- **Description:** Genetic variance from common variants using permuted AFs
- **Note:** Only present when permuted AFs are available

### **vg_rare_perm**
- **Type:** Float
- **Description:** Genetic variance from rare variants using permuted AFs
- **Note:** Only present when permuted AFs are available

---

## Spatial Window Vg Metrics

### **vg_distal_upstream**
- **Type:** Float
- **Description:** Total Vg contribution from distal upstream region (-10kb to -2kb)

### **vg_proximal_upstream**
- **Type:** Float
- **Description:** Total Vg contribution from proximal upstream region (-2kb to -200bp)

### **vg_promoter_core**
- **Type:** Float
- **Description:** Total Vg contribution from core promoter region (-200bp to +200bp)

### **vg_down_proximal**
- **Type:** Float
- **Description:** Total Vg contribution from downstream proximal region (+200bp to +2kb)

### **vg_down_distal**
- **Type:** Float
- **Description:** Total Vg contribution from downstream distal region (+2kb to +10kb)

### **vg_[window]_perm**
- **Type:** Float
- **Description:** Vg contribution from each spatial window using permuted AFs
- **Windows:** distal_upstream, proximal_upstream, promoter_core, down_proximal, down_distal
- **Note:** Only present for real data with permuted AFs

## Genetic Variance Confidence Intervals (Monte Carlo)

### **vg_perm_mean**
- **Type:** Float
- **Description:** Mean Vg from Monte Carlo permutation simulation
- **Method:** Random sampling of AFs from gene-specific pool (default 1000 iterations)
- **Note:** Only present when calculate_ci=True

### **vg_perm_p05**
- **Type:** Float
- **Description:** 5th percentile of Vg distribution from permutation
- **Interpretation:** Lower bound of 90% confidence interval

### **vg_perm_p95**
- **Type:** Float
- **Description:** 95th percentile of Vg distribution from permutation
- **Interpretation:** Upper bound of 90% confidence interval

---

## Genetic Architecture Metrics

### **N90**
- **Type:** Integer
- **Description:** Number of variants contributing to 90% of total Vg
- **Interpretation:** Lower values indicate more oligogenic architecture

### **N85**
- **Type:** Integer
- **Description:** Number of variants contributing to 85% of total Vg

### **variance_N90**
- **Type:** Float
- **Description:** Cumulative variance captured by the N90 variants

### **cv_effect_N90**
- **Type:** Float
- **Description:** Coefficient of variation of effect sizes among N90 variants
- **Formula:** std(effect_sizes_N90) / mean(effect_sizes_N90)
- **Interpretation:** Measures heterogeneity of top effect sizes

### **mean_effect_N90**
- **Type:** Float
- **Description:** Mean absolute effect size of the N90 variants

### **N90_perm**, **N85_perm**, **variance_N90_perm**, **cv_effect_N90_perm**, **mean_effect_N90_perm**
- **Type:** Integer/Float
- **Description:** Architecture metrics calculated using permuted AFs
- **Note:** Only present for synthetic data (is_synthetic=True)

## Entropy Metrics (Effect Size Heterogeneity)

### **entropy_effect**
- **Type:** Float
- **Description:** Shannon entropy of all effect sizes
- **Formula:** -Σ(p × log(p)) where p = effect_i / Σ(effects)
- **Interpretation:** Higher values indicate more uniform effect size distribution

### **entropy_distal_upstream**
- **Type:** Float
- **Description:** Shannon entropy of effects in distal upstream region

### **entropy_proximal_upstream**
- **Type:** Float
- **Description:** Shannon entropy of effects in proximal upstream region

### **entropy_promoter_core**
- **Type:** Float
- **Description:** Shannon entropy of effects in core promoter region

### **entropy_down_proximal**
- **Type:** Float
- **Description:** Shannon entropy of effects in downstream proximal region

### **entropy_down_distal**
- **Type:** Float
- **Description:** Shannon entropy of effects in downstream distal region

## Selection Signature Metrics

### **weighted_mean_effect**
- **Type:** Float
- **Description:** Allele frequency-weighted mean absolute effect
- **Formula:** Σ(AF × |effect|) / Σ(AF)
- **Interpretation:** Lower values suggest selection against high-impact variants

### **weighted_mean_effect_perm**
- **Type:** Float
- **Description:** Weighted mean effect using permuted AFs
- **Note:** Only present for real data with permuted AFs

### **af_gradient**
- **Type:** Float
- **Description:** Spearman correlation between distance to TSS and allele frequency
- **Interpretation:** Positive = higher AF farther from TSS; Negative = higher AF near TSS

---

## Notes on Data Availability

- **Permuted AF metrics** (_perm suffix): Only present when input data contains permuted allele frequencies
- **Monte Carlo CI metrics** (vg_perm_mean, vg_perm_p05, vg_perm_p95): Only present when calculate_ci=True
- **Depletion scores**: Only present for real data with permuted AFs (not in synthetic mode)
- **Architecture metrics** (_perm suffix): For synthetic data, architecture metrics use permuted AFs by default

---

## Spatial Window Definitions

All distance-based windows are calculated relative to the transcription start site (TSS) in strand-aware manner:

1. **Distal Upstream**: -10,000 to -2,000 bp
2. **Proximal Upstream**: -2,000 to -200 bp
3. **Core Promoter**: -200 to +200 bp
4. **Downstream Proximal**: +200 to +2,000 bp (includes 5' UTR and early gene body)
5. **Downstream Distal**: +2,000 to +10,000 bp

Positive distances are downstream (in direction of transcription), negative are upstream.

## Formulas & Key Calculations

### Genetic Variance (Vg)
```
vg_contribution = 2 × AF × (1 - AF) × β²
```
where:
- AF = allele frequency
- β = raw effect score (signed)

### Enrichment Score
```
enrichment = (vg_window / n_variants_window) / (vg_total / n_variants_total)
```

### Depletion Score
```
depletion = mean(AF_subset) / mean(perm_AF_subset)
```

### Shannon Entropy
```
entropy = -Σ(p_i × log(p_i))
```
where p_i = effect_i / Σ(effects)
